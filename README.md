# AI 안경

폰 카메라로 객관식 문제를 비추고 화면을 탭하면 찍어서 풀고, 정답만 크게 보여주는 웹 페이지입니다.

**바로 열기:** https://leehwon0217.github.io/AI-Glasses/

## 쓰는 법

1. 폰에서 위 주소를 열고 카메라 권한을 허용합니다.
2. 처음 한 번, 설정(⚙)에 Claude 또는 OpenAI API 키를 넣고 저장합니다. 키가 `sk-ant-`로 시작하면 Claude로, 아니면 OpenAI로 풉니다.
3. 박스 아래의 **↕ 크기** 손잡이를 위아래로 끌어 박스를 문제 모양에 맞춥니다. 가로로 긴 문제는 낮게, 세로로 긴 문제는 높게 맞추면 문제 하나만 크게 담을 수 있습니다. 맞춘 크기는 저장됩니다.
4. **박스 안에 문제를 넣고 화면을 탭합니다.** 탭하고 잠깐(약 0.5초) 폰을 그대로 두면 그 사이 가장 또렷한 장면을 골라 찍습니다.
5. 박스 아래에 정답이 "12번: 3"처럼 문제 번호와 함께 나옵니다. 박스에 다른 문제가 섞여 들어와도 박스 가운데의 문제 하나만 풉니다. 답 아래에는 **AI에게 보낸 사진**이 작게 나오니, 답이 이상하면 문제가 잘리거나 흐리게 찍히지 않았는지 확인하세요.
6. 푼 답은 화면 **오른쪽 위 기록**에 계속 쌓여서 나중에 다시 볼 수 있습니다. 페이지를 닫아도 남고, "기록 지우기"로 비웁니다.
7. 다음 문제를 박스에 넣고 **다시 탭**하면 곧바로 그 문제를 찍습니다. 탭하기 전에 폰을 움직이면 이전 답은 화면에서 지워지지만 기록에는 남습니다.

## 교안을 근거로 풀기 (오픈북)

과목 교안을 폰에 넣어 두면, 고른 과목의 교안 전문을 문제와 함께 AI에게 보내 교안을 근거로 답하게 합니다.

1. PC에서 `python tools/make_materials.py "PDF가 있는 폴더"` 를 실행합니다. (`pip install pymupdf cryptography` 필요) 암호화된 `materials.enc`와, 열쇠가 든 `교안/설정링크.txt`가 만들어집니다.
2. `materials.enc`를 커밋해서 올립니다.
3. 폰에서 `교안/설정링크.txt`의 링크를 **한 번** 엽니다. 교안이 자동으로 받아져 그 폰 브라우저에 저장됩니다. 교안을 새로 올리면 다음에 열 때 자동으로 갱신됩니다.
4. 화면 위 초록색 **과목 선택**에서 시험 과목을 고릅니다. "교안 없이"를 고르면 교안을 보내지 않습니다.

교안은 저작권이 있는 자료라 원문은 저장소에 올리지 않고(`교안/` 폴더는 git에서 제외), 암호화한 `materials.enc`만 올립니다. 설정 링크의 열쇠가 있어야 풀립니다. 설정(⚙)의 **교안 파일**에서 `교안/교안.json`을 직접 고르는 방법도 됩니다. "설정 링크 복사"로 만든 링크에는 API 키와 교안 열쇠가 함께 들어갑니다.

## 화면 상태

| 박스 테두리 | 상단 문구 | 뜻 |
|---|---|---|
| 흰색 | 박스에 문제를 넣고 탭하세요 | 대기 중 |
| 박스 전체가 파랗게 덮이고 "푸는 중 N초" | 찍었어요 · 푸는 중… N초 | AI가 푸는 중 |
| 굵은 초록 | ✅ 풀이 끝 · 다음 문제 넣고 탭 | 답 표시 중 |

## 설정

- **API 키:** 그 폰의 브라우저에만 저장되고, 이 저장소나 다른 서버에는 올라가지 않습니다. Claude 키는 platform.claude.com에서, OpenAI 키는 platform.openai.com에서 발급하고 크레딧을 충전해야 합니다. Claude·ChatGPT 구독과는 별개입니다.
- **모델:** 기본값 "자동"은 Claude 키면 Claude Opus 5.5를, OpenAI 키면 가장 높은 버전의 gpt를 씁니다. 목록에서 직접 고를 수도 있습니다.
- **풀이 깊이:** 가장 빠르게 / 빠르게(기본) / 보통 / 꼼꼼하게. 깊을수록 정확하지만 느립니다. "가장 빠르게"는 고른 모델이 받는 가장 가벼운 추론 설정을 자동으로 찾아 씁니다.
- **음성 읽기:** 정답을 소리로 읽어줍니다.
- **설정 링크 복사:** 키가 담긴 링크를 만들어 다른 폰에 보내면, 그 폰에서 한 번 여는 것으로 키가 저장됩니다. 링크에 키가 들어 있으니 믿을 수 있는 사람에게만 보내세요.

## 구조

빌드 과정과 서버가 없는 정적 페이지입니다.

- `index.html` — 화면 구성
- `style.css` — 스타일
- `tools/make_materials.py` — 교안 PDF에서 글자를 뽑아 암호화 파일을 만드는 스크립트
- `materials.enc` — 암호화된 교안
- `app.js` — 카메라, 박스 영역 촬영, OpenAI 호출, 결과 표시

박스 영역만 잘라서 Claude Messages API 또는 OpenAI Chat Completions API로 보내며, 브라우저가 API를 직접 호출합니다.

## 로컬에서 실행

```bash
python -m http.server 8765
```

그다음 `http://localhost:8765` 를 엽니다. 카메라는 HTTPS나 localhost에서만 동작합니다.
