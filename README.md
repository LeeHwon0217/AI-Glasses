# AI 안경

폰 카메라로 객관식 문제를 비추면 자동으로 찍어서 풀고, 정답만 크게 보여주는 웹 페이지입니다.

**바로 열기:** https://leehwon0217.github.io/AI-Glasses/

## 쓰는 법

1. 폰에서 위 주소를 열고 카메라 권한을 허용합니다.
2. 처음 한 번, 설정(⚙)에 OpenAI API 키를 넣고 모델을 고른 뒤 저장합니다.
3. 화면의 **정사각형 박스 안에 문제를 넣고 1초 멈춥니다.** 초록 게이지가 다 차면 자동으로 찍습니다.
4. 박스 아래에 정답이 "3번"처럼 크게 나옵니다. 문제가 여러 개 찍히면 "12: 3번"처럼 문제 번호와 함께 나옵니다.
5. 다음 문제를 박스 안에 넣고 **화면을 탭**하면 이전 답이 지워지고, 멈춰 있으면 곧바로 다음 문제를 찍습니다.

답이 떠 있지 않을 때 화면을 탭하면 1초를 기다리지 않고 바로 찍습니다.

## 화면 상태

| 박스 테두리 | 상단 문구 | 뜻 |
|---|---|---|
| 흰색 | 박스에 문제를 넣고 1초 멈추세요 | 대기 중 |
| 초록 + 게이지 | (같음) | 멈춤 감지 중, 곧 촬영 |
| 파란색 깜빡임 | 찍었어요 · 푸는 중… N초 | AI가 푸는 중 |
| 굵은 초록 | ✅ 풀이 끝 · 다음 문제는 탭 | 답 표시 중, 탭할 때까지 유지 |

## 설정

- **OpenAI API 키:** 그 폰의 브라우저에만 저장되고, 이 저장소나 다른 서버에는 올라가지 않습니다. ChatGPT 구독과는 별개이며 platform.openai.com에서 발급하고 크레딧을 충전해야 합니다.
- **모델:** 키를 넣으면 그 키로 쓸 수 있는 모델 목록을 불러옵니다.
- **풀이 깊이:** 빠르게 / 보통 / 꼼꼼하게. 깊을수록 정확하지만 느립니다.
- **멈춤 감지:** 왼쪽일수록 완전히 멈춰야 찍습니다.
- **음성 읽기:** 정답을 소리로 읽어줍니다.
- **설정 링크 복사:** 키가 담긴 링크를 만들어 다른 폰에 보내면, 그 폰에서 한 번 여는 것으로 키가 저장됩니다. 링크에 키가 들어 있으니 믿을 수 있는 사람에게만 보내세요.

## 구조

빌드 과정과 서버가 없는 정적 페이지입니다.

- `index.html` — 화면 구성
- `style.css` — 스타일
- `app.js` — 카메라, 멈춤 감지, 박스 영역 촬영, OpenAI 호출, 결과 표시

박스 영역만 잘라서 OpenAI Chat Completions API로 보내며, 브라우저가 API를 직접 호출합니다.

## 로컬에서 실행

```bash
python -m http.server 8765
```

그다음 `http://localhost:8765` 를 엽니다. 카메라는 HTTPS나 localhost에서만 동작합니다.
